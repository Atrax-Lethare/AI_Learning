# AI Mastery

A structured learning repository documenting my journey from **AI fundamentals to advanced AI research and engineering**.

This repository contains everything I learn along the way: **mathematics, AI concepts, implementations, projects, experiments, research papers, external resources, and learning discussions**.

## What You'll Find Here

* 🧮 **Mathematics** — The mathematical foundations behind AI and machine learning.
* 🧠 **AI Concepts** — Machine learning, deep learning, Transformers, LLMs, RAG, agents, reinforcement learning, and more.
* ⚙️ **AI Engineering** — Building, deploying, evaluating, optimizing, and maintaining real-world AI systems.
* 🔬 **Research** — Papers, reproductions, experiments, research ideas, and open problems.
* 🛠️ **Projects & Experiments** — Practical implementations that turn concepts into working systems.
* 📚 **Resources** — Books, courses, papers, documentation, tutorials, repositories, and other useful sources.
* 💬 **Learning Logs** — Discussions, questions, challenges, mistakes, and insights from the learning process.

## Learning Philosophy

The goal is not simply to **know AI**, but to progressively develop the ability to:

> **Understand → Implement → Experiment → Build → Research**

This repository serves as both a **knowledge base** and a record of that progression.

*Still learning. Still building. Still breaking things. Probably mostly the last one.*
