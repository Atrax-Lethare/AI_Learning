# What is a vector?

A vector is a depiction of a point in a space of n-dimensions. 
*This is a very Physics-driven definition. While it can be true in machine learning as well, strictly defining it like this wouldn't make sense.*

**The machine learning definition:**
    A ***vector*** is a mathematical representation of anything in the real world. 

Vectors are used to represent real-world entities, observations, etc. in mathematical form, such that they can be analyzed mathematically by calculations and derive insights on the same.

A vector can be represented as follows: (1, 2) or [2, 88, 10]

# Components of a vector

[1, 2, 3, 4, 5...]
    Each number in this vector is a component of the vector

# Features of a vector

Each component of a vector represents a particular feature of the "thing" being represented by the vector. 
E.g., if the vector represents a human, each component can represent a feature of the human. (*The vectors actually used in concepts like embeddings (for neural networks) don't actually have just some features, so that they can be tagged with a feature and understood. There are hundreds to thousands of features in a vector processed by neural networks. These have some algorithmic meaning, which can be understood by the neural network and processing is conducted.*)

# Dimension of a vector

The number of components in a vector is known as the vector's dimension. 

At a smaller scale, for smaller, easily interpretable vectors, the dimension can mean how many features are considered.
At a higher scale, for the entities processed by neural networks, the dimension can mean how good and enormous of information the vector holds of the entity.

# Magnitude and dimension of a vector

These are mathematical concepts used for calculcations, such as similarity between two vectors, new vectors with combined traits etc.

*Magnitude* is the square root of the sum of the squares of all the components in a vector.
*Direction* is the angle made by the vector with a reference axis.

These are extremely basic definitions or the magnitude and direction of a vector. As we progress in machine learning, we will learn a lot of ways to mathematically represent these quantities.

***Intuition***:
    Magnitude represents how large a particular vector is, while its direction represents its relative alignment.

# Scalar and dot multiplication 

*Scalar multiplication* is the multiplication of a scalar quantity with a vector, which leads to multiplication of the scalar to all the components of the vector.

Ex.: 2 * [1, 2, 3] = [2, 4, 6]

*Dot multiplication* is a type of multiplication between 2 vectors (*yes... there can be other types of multiplications between 2 vectors*), where each component of a vector is multiplied to the corresponding component of the other vector, and all these products are added together. This multiplication is only possible between vectors of the same dimensions. 

Ex.: [1, 2, 3].[1, 2, 3] = 1\*1 + 2\*2 + 3*3 = 14

# Vector addition

It is the addition of two vectors of the **same dimension**, which leads to addition of a component of a vector to the corresponding component of the other vector. 

Vector addition doesn't necessarily have a representation - the operation's result can be given any meaning by the developer, in the prediction algorithm (the operation can be given a semantic meaning). 

Ex.: [1, 2, 3] + [1, 2, 3] = [2, 4, 6]

# What does an operation on a vector depict?

We know that a vector represents a real-world thing. Any operation on a vector can represent a change to the real world thing, which can tell us a lot about the thing. Hence, an operation on a vector depicts analysis on the real-world thing it is depicting.

# Distance between vectors

A = [a1, a2, a3, ...]
B = [b1, b2, b3, ...]

Euclidean distance between A and B = sq. root of ((b1 - a1)^2 + (b2 - a2)^2 + ...)

This is one of the similarity measures between vectors - smaller distance => more similar.

# Cosine similarity between vectors

It is measured by the cosine of the angle between the vectors from a reference origin for the coordinate system considered. 

Cosine = 0 => Perpendicular vectors, not at all similar
Cosine = 1 => Overlapping vectors, completely similar
Cosine = -1 => Opposite vectors, completely opposite

Provides directional similarity.

# Why different similarity measures exist? 

Because two vectors can be similar in multiple ways.

- Magnitude: Similar if closer magnitude values.
- Direction: Similar if cosine similarity closer to 1, i.e. if the directions are close.
- Distance: Similar if the vectors are closer to each other. (can be imagined in terms of vectors being points in a space)

There are plenty of other ways similarity can be measured, because of the diverse nature of vectors.

# Does representation quality matter? Why?

Yes, representation quality matters. 
Because if the representation doesn't hold the characteristics of the real-world thing being dealt with properly, then the operations on it would return absurd conclusions about the thing. To make analysis on these vector representations of the things meaningful, their quality must be really good.
