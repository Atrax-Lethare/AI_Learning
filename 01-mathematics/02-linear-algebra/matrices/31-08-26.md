## What is a matrix? 

Mathematically, a matrix is just a rectangular array of numbers whose dimensinos are described by the denotion "rows x columns".

Intuitively (as per machine learning), it is a representation of a transformation that can be applied to a vector, by producing a new vector by combining the features of the input vectors with different weights to result into new feature values. 

A more technical definition: **A matrix is a structured transformation that takes numerical representations and produces new numerical representations by combining their components according to learned or specified weights.**

## Intuition about vectors, matrices and matrix multiplication

Vector = representation of information

Matrix = transformation of that information

Matrix multiplication = weighted combinations producing a new representation

When those weights are learned from data, the matrix becomes part of a machine-learning model.
